# Components Directory

Reusable React components used across the application.

## What Goes Here

- UI components (buttons, inputs, cards, modals, etc.)
- Layout components (header, footer, sidebar, navigation)
- Feature-specific components that are reused
- Each component should ideally have its own folder with:
  - `ComponentName.tsx/jsx` - Component implementation
  - `ComponentName.module.css` or styled components
  - `ComponentName.test.tsx/jsx` - Component tests
  - `index.ts` - Export file

## Organization Tips

- Keep components small and focused
- Group related components in subfolders
- Separate presentational and container components

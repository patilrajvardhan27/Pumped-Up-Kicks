# Pages Directory

Page-level components that represent different routes in the application.

## What Goes Here

- Route components that correspond to different URLs
- Each page should be in its own file or folder
- Pages compose multiple components to create full views
- Examples:
  - `HomePage.tsx` - Landing page
  - `DashboardPage.tsx` - User dashboard
  - `VideoUploadPage.tsx` - Video upload interface
  - `VideoDetailPage.tsx` - Individual video view
  - `LoginPage.tsx` - Authentication page
  - `SettingsPage.tsx` - User settings

## Organization

Pages should focus on layout and composition, delegating logic to hooks and business logic to services.

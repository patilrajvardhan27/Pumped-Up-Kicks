# Utils Directory

Utility functions and helper modules.

## What Goes Here

- Pure functions that perform common operations
- Format helpers (dates, numbers, strings)
- Validation functions
- Constants and enums
- Type definitions and interfaces (or create a separate `types/` folder)
- Examples:
  - `formatters.ts` - Date, time, file size formatting
  - `validators.ts` - Input validation functions
  - `constants.ts` - Application constants
  - `helpers.ts` - Miscellaneous helper functions

## Guidelines

- Functions should be pure and testable
- No side effects or external dependencies
- Well-documented with JSDoc comments
- Unit tested

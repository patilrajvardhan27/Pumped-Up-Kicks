# Source Directory

Main source code for the frontend application.

## Directory Structure

- `assets/` - Images, fonts, and other media files used in components
- `components/` - Reusable React components
- `contexts/` - React Context providers for global state
- `hooks/` - Custom React hooks
- `pages/` - Page-level components (route components)
- `services/` - API clients and external service integrations
- `utils/` - Utility functions and helpers

## What Goes Here

- `App.tsx/jsx` - Main application component
- `index.tsx/jsx` - Application entry point
- `routes.tsx/jsx` - Route definitions
- Global styles and theme files

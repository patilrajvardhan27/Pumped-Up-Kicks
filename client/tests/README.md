# Tests Directory

Test files and testing utilities for the frontend application.

## What Goes Here

- Integration tests
- E2E (end-to-end) tests
- Test utilities and helpers
- Mock data and fixtures
- Testing configuration files
- Examples:
  - `setup.ts` - Test environment setup
  - `helpers.ts` - Testing helper functions
  - `mocks/` - Mock data and API responses
  - `e2e/` - End-to-end test scenarios

## Note

Unit tests for individual components should live alongside the components in `__tests__` folders or as `.test.tsx` files.

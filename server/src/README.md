# Server Source Directory

Main source code for the backend application.

## Directory Structure

- `api/` - HTTP API endpoints (controllers and routes)
- `config/` - Configuration files and environment setup
- `jobs/` - Background jobs and scheduled tasks
- `middleware/` - Express middleware functions
- `models/` - Database models and schemas
- `services/` - Business logic and external service integrations
- `utils/` - Utility functions and helpers

## What Goes Here

- `index.ts/js` - Application entry point
- `app.ts/js` - Express app configuration
- `server.ts/js` - Server initialization

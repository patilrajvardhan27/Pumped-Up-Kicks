# Embeddings Service

AI embedding generation for semantic search and similarity matching.

## What Goes Here

- Text embedding generation (OpenAI, Cohere, local models)
- Vector storage integration (Pinecone, Weaviate, Chroma)
- Similarity search implementation
- Embedding model configuration

## Use Cases

- Semantic search through video transcriptions
- Content recommendation
- Clustering similar videos
- Question answering over video content

## Files Example

- `embeddingGenerator.ts` - Generate embeddings from text
- `vectorStore.ts` - Store and query vectors
- `similaritySearch.ts` - Find similar content

# Services Directory

Business logic and external service integrations.

## Directory Structure

- `embeddings/` - AI embedding generation services
- `rag/` - Retrieval Augmented Generation implementation
- `transcription/` - Speech-to-text services
- `video-processing/` - Video manipulation and processing

## What Goes Here

Core business logic that:
- Orchestrates multiple operations
- Integrates with external APIs
- Implements complex algorithms
- Handles data transformations
- Manages third-party services

## Best Practices

- Services should be framework-agnostic
- Keep services testable and mockable
- Handle errors and edge cases
- Use dependency injection where appropriate

# Models Directory

Database models and schemas.

## What Goes Here

- Database model definitions
- Schema validations
- Model methods and statics
- Examples:
  - `User.ts` - User model
  - `Video.ts` - Video metadata model
  - `Transcription.ts` - Transcription data model
  - `Embedding.ts` - AI embedding vectors

## ORM/ODM

Depending on your database:
- Mongoose for MongoDB
- Sequelize/TypeORM for SQL databases
- Prisma for type-safe database access

Models should encapsulate data structure, validation, and basic queries.

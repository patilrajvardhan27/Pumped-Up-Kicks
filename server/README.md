# Server

Backend application for Pumped Up Kicks - a video processing platform with AI-powered features.

## Directory Structure

- `src/` - Source code for the backend application
- `tests/` - Backend tests and test utilities
- `uploads/` - Temporary storage for uploaded files

## Features

Based on the directory structure, this server handles:
- Video processing and transcription
- AI embeddings and RAG (Retrieval Augmented Generation)
- RESTful API endpoints
- Background job processing
